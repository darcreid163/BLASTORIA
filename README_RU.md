# BLASTORIA — Prototype 0.1

Оригинальная 2.5D аркада-лабиринт, вдохновлённая классикой жанра. Исходный проект Godot на GDScript без платных ассетов.

## Запуск
1. Скачать **Godot 4.7.2 Standard**: https://godotengine.org/download/archive/4.7.2-stable/
2. Распаковать ZIP проекта в папку.
3. Godot → Import → выбрать `project.godot` → Import & Edit.
4. Нажать F6/F5 (Play Project — F5).

## Управление
- Игрок 1: WASD, ПРОБЕЛ — поставить бомбу.
- Игрок 2: стрелки, ENTER — поставить бомбу (только арена).
- F1 — кампания; F2 — локальный бой двух игроков; R — перезапуск по завершении.

## Уже реализовано
- Настоящая 3D-сцена с фиксированной наклонной камерой, цветами и освещением.
- 15×11 клеток, неразрушаемые блоки и разрушаемые ящики.
- Две схемы управления, локальная арена на двоих.
- Таймеры бомб, крестообразные взрывы, цепные реакции, поражение от огня.
- Кампания с врагами и выходом, переход на следующий случайно созданный уровень.
- Простейший движущийся ИИ врагов.

## Ограничения раннего прототипа
- Графика процедурная, без финальных моделей, музыки и анимаций.
- Нет сохранений, геймпадов, сетевого режима, Steam SDK, меню и установщика.
- Базовый ИИ упрощён и не гарантирует избегание ловушек.
- Экспортированный .exe пока не включён: для этого необходимы официальные export templates Godot.
- Проект создан как начальный исходный код; проверка запуска в Godot в данной среде не выполнялась.

Это новый прототип с оригинальным названием BLASTORIA. Не использует игровые файлы Bomberman/Konami. Коммерческое название необходимо дополнительно проверить на товарные знаки.
