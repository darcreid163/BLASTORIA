# Классические правила и пресет BLASTORIA 0.4

Источники и границы достоверности:
- [Текстовая транскрипция руководства Hudson Soft для NES](https://www.world-of-nintendo.com/manuals/nes/bomberman.shtml).
  Подтверждает скрытый под кирпичами выход, необходимость уничтожить врагов, опасность контакта
  и огня, неразрушимые стены, усиления, дистанционный подрыв и бонусный раунд после пяти уровней.
  Это перепечатка руководства, а не проверенная нами эмуляция оригинала.
- [Скан руководства Classic NES Series — Bomberman, GBA](https://www.videogamemanual.com/gba/Classic%20NES%20Series%20-%20Bomberman%20(USA).pdf).
  Найден для дальнейшей сверки; это переиздание, его параметры не выдаются за замеры NES.

Стартовый радиус 1, лимит 200 игровых секунд и полный набор восьми усилений заданы
утверждённым MASTER_SPEC.md. Точный темп таймера NES, численность исторических подкреплений
и таблица исторических очков пока не подтверждены первичными замерами. Пресет 0.4 —
классическая механика с явно выбранными параметрами BLASTORIA, не сертифицированная эмуляция NES.

## Реализованный пресет

| Параметр | Классика 0.4 | Приключение 0.4 |
| --- | --- | --- |
| Карта | 21×15; три тестовых уровня | 41×31; один исследовательский уровень |
| Начальные бомбы / радиус | 1 / 1 | 1 / 2 |
| Фитиль / огонь | 150 / 30 тиков при 60 Гц | Те же |
| Таймер | 200 игровых секунд, пока 60 тиков на секунду | Без лимита |
| Контакт с врагом | Смертелен без временной защиты | То же |
| Выход | Под блоком; все враги должны быть побеждены | То же |
| Повторный взрыв по открытому выходу | Два Стража за новую волну взрывов | Нет наказания |
| Нулевой таймер | Однократно четыре Стража; счётчик остаётся на нуле | Не применяется |
| Очки | Ящик +10, враг +100, предмет +25, выход +500 | То же; компас +50 000 |

Только разрушения/убийства от огня игрока дают очки. Следы огня не повторяют выдачу.
Уничтожение блока над выходом само по себе не вызывает подкрепление. Стражи появляются
на свободных безопасных клетках не ближе пяти клеток по Manhattan-расстоянию от игрока;
ожидающие подкрепления блокируют победу. Не более 32 живых врагов и 32 ожидающих.
Звёздная/рейтинговая таблица для Классики ещё не реализована. Arcade v1 остаётся отдельно.

## Усиления

В Классике и Приключении гарантированно спрятан экземпляр каждого из восьми усилений.
Дополнительные случайные предметы — Bomb/Fire/Speed Up. Предметы видны и доступны после
затухания огня, не сгорают: это выбранное правило BLASTORIA.

| Предмет / метка | Эффект и предел | Взаимодействия |
| --- | --- | --- |
| Bomb Up / +B | Вместимость +1, максимум 5 | Не меняет уже поставленные бомбы |
| Fire Up / +R | Радиус +1, максимум 6 | Радиус фиксируется при установке |
| Speed Up / +S | Период шага −1, минимум 5 тиков | Нет диагонального ускорения |
| Remote / RC | E / B на геймпаде взрывает старейшую свою дистанционную бомбу | Новые бомбы ждут команды, но реагируют на чужой огонь; старые обычные сохраняют фитиль |
| Wall Pass / WP | Проход сквозь разрушаемые блоки | Прочные стены непроходимы; внутри блока нельзя поставить бомбу |
| Bomb Pass / BP | Проход сквозь бомбы | Не защищает от взрыва |
| Flame Pass / FP | Защита от огня | Контакт с врагом остаётся опасным |
| Invulnerability / IV | Защита от огня и контакта на 1800 тиков | Повторное получение обновляет срок; пауза замораживает его |

Классика: между уровнями сохраняются постоянные способности и счёт; временная защита
сбрасывается. При поражении/повторе сохраняются только Bomb/Fire Up, остальные способности
сбрасываются; очки возвращаются к значению на входе в уровень, чтобы повтор не дублировал награды.
Приключение: повтор сбрасывает способности и очки; найденная коллекция сохраняется.
Один игровой персонаж/одна попытка, с ручным повтором. Банк жизней пока не реализован.

В планах: серия из 50 оригинальных уровней, бонусные раунды после каждого пятого,
отдельная таблица очков, расширенные типы врагов и дальнейшая сверка исторического пресета.
