находятся только 17 реализованных открытых достижений. Будущие и скрытые определения
в неё не включены. Это локальный прогресс; Steamworks не подключён.

иконка/название/описание/прогресс, дата получения UTC; API ID и скрытые слоты не выводятся.

Квалифицируемая Арена: не меньше 30 активных секунд; оба игрока сделали не меньше
трёх успешных шагов и поставили хотя бы по бомбе. Поражение игрока 1 не считается его
победой. Критерии затрудняют начисление за мгновенные/пустые матчи, но не являются серверной защитой.

Пользовательские карты и editor playtest не увеличивают официальные боевые счётчики.
Мастерская даёт только свои достижения. Импорт не считается авторством; копирование,
смена названия/ID/revision/seed без изменения игрового содержимого не создаёт новую геометрию.

## Откуда берутся события

GameState.activity считает принятые команды, реальные взрывы, движение, урон и подбор.
BombSystem отслеживает причинные корни цепей; несколько независимых фитилей в один тик
не объединяются в цепочку. Награда не зависит от нажатия кнопки меню. AchievementManager
учитывает только новые дельты попытки и однократно принимает её завершение.
CustomMapLibrary сообщает об успешных сохранении, импорте и экспорте после фактической записи.

При запуске F5 из Godot / debug export получение отключено, просмотр доступен. В release export
оно включено. Изолированные тесты используют прямой override без игрового UI. Обход владельцем
клиента через изменение исходников не считается решённой задачей.

## Сохранение и Steam

user://milestones.progress — отдельный зашифрованный контейнер с версией, счётчиками,
полученными записями, ограниченным набором обработанных попыток и очередью будущей Steam-синхронизации.
Ключи формата совместимы с действующим локальным codec; старый профиль v5/коллекция не меняются.
Сохраняется при награде, завершении, переходах/выходе и каждые пять активных секунд при изменениях.
После аварийного завершения возможна потеря незаписанных последних секунд счётчиков.

Пишется временный файл, резервная копия берётся только из корректного предыдущего файла.
Повреждённый primary восстанавливается из аутентифицированной копии. Будущая версия блокирует
перезапись. Ошибка диска сохраняет новые данные в памяти для повторной записи.

Очередь сохраняется однократно на достижение, но пока никому не отправляется. В будущем
адаптер должен проверить состояние Steam и подтверждение записи перед удалением элемента.
Серверное первенство не выдаётся никаким локальным событием; нужных скрытых определений
в клиентском payload этой версии вообще нет.
