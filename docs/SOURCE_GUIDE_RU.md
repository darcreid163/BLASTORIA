# Для чего нужен Godot_Source.zip и как его запустить

`BLASTORIA_0_2_1_Godot_Source.zip` — проект игры для редактора Godot: код, сцены,
параметры и документация. Он нужен, чтобы запускать игру из редактора, менять механику,
карты и интерфейс, продолжать разработку и собирать EXE. Это не установщик Windows.
Архив `BLASTORIA_0_4_0_Godot_Source.zip` устроен так же, но содержит новый этап разработки.

1. Распакуйте **весь ZIP** в обычную папку, например `C:\Games\BLASTORIA_Source`.
2. Скачайте [Godot 4.5.1 Standard для Windows](https://godotengine.org/download/archive/4.5.1-stable/).
   Нужна обычная версия, без .NET: проект написан на GDScript. Распакуйте и запустите редактор.
3. В менеджере проектов нажмите **Import / Импортировать** и выберите файл
   `project.godot` внутри распакованной папки BLASTORIA (он может лежать во вложенной папке).
4. Нажмите **Import & Edit / Импортировать и редактировать**, дождитесь окончания импорта ресурсов.
5. Нажмите **F5** или кнопку запуска проекта сверху справа. Откроется главное меню.
   В версии 0.4.0 начните с «Обучения». F8 останавливает запущенную из редактора игру.

Открывать отдельный `.gd` вместо `project.godot` не нужно. Не запускайте проект прямо внутри ZIP.
Если Godot сообщает об ошибке импорта, убедитесь, что распаковали весь архив и используете 4.5.1;
пришлите полный текст ошибки. Папка `.godot` создаётся редактором автоматически.

Для обычной игры редактор и исходники не нужны: распакуйте архив `Windows_x64.zip`
и запустите `BLASTORIA.exe`. Для самостоятельной сборки EXE из исходников дополнительно
нужны экспортные шаблоны Godot **4.5.1**; для запуска по F5 они не требуются.

В меню: «Обучение», кампания, одиночная «Аркада» с очками/временем и арена на двоих.
По умолчанию WASD + Пробел; второй игрок — стрелки + Enter. Esc — пауза, F11 — полный экран.
В 0.4.0 клавиши меняются через «Настройки»; «Назад и сохранить» записывает настройки.

Новое в 0.4: «Приключение» → «Войти в древние руины» для карты 41×31.
«Классика» запускает три тестовых этапа. E — дистанционный подрыв после получения RC;
Tab — переключение карты. Управление и изменения клавиш сохраняются между запусками.
