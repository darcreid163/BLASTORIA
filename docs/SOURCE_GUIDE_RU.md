# Как запустить исходники BLASTORIA

`BLASTORIA_0_5_0_Godot_Source.zip` содержит проект Godot: код, сцены, данные карт,
ресурсы, документацию и тесты. Он нужен для разработки и самостоятельной сборки.
Ранее выданный `BLASTORIA_0_2_1_Godot_Source.zip` имел ту же роль для старой версии.

1. Установите **Godot 4.5.1 Standard**, без .NET (код написан на GDScript).
2. Распакуйте ZIP целиком в отдельную папку.
3. В менеджере проектов Godot нажмите Import / «Импорт» и выберите `project.godot`.
4. Откройте проект и дождитесь завершения импорта ресурсов.
5. Нажмите **F5** для запуска всей игры. F8 останавливает запуск из редактора.

Для обычной игры удобнее `BLASTORIA_0_5_0_Windows_x64.zip`: распакуйте и запустите
`BLASTORIA.exe`. Godot для него не нужен. Windows-сборка экспортирована, но в этой
среде не запускалась на Windows; при ошибке пришлите текст/снимок ошибки и характеристики ПК.

В 0.5: «Аркада» → «01 · Двор садовника». Следующий этап открывается после уничтожения
обязательных врагов; искать выход не требуется. Готовы первые три этапа.
«Мастерская карт» → настройки → генерация → «Проверить карту» → возврат в редактор.
Сохраните понравившуюся карту; `.blastmap` можно экспортировать и передать другу.

Управление игрока 1: стрелки, Space — бомба, E — детонатор (если получен).
Игрок 2: WASD, Enter — бомба, P — детонатор. Esc — пауза, F11 — полный экран.
Личные переназначения сохраняются; сброс к стандартным клавишам находится в Настройках.

При обновлении распаковывайте сборки отдельно. user://profile.json сохраняет старые
настройки/прогресс; новые официальные и пользовательские результаты имеют отдельные файлы.
Новый ZIP не удаляет пользовательские карты.
