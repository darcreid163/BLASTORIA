# Запуск BLASTORIA 0.6.1 в Godot

1. Распакуйте BLASTORIA_0_6_1_Godot_Source.zip целиком.
2. В Godot **4.5.1 Standard** импортируйте project.godot.
3. Дождитесь импорта и нажмите **F5**. F8 останавливает игру из редактора.
4. Кампания → начало/продолжение; первые десять этапов имеют разные авторские карты.
5. Стрелки / Space / E — игрок 1; WASD / Enter / P — игрок 2. Esc — пауза.

В архив уже включены шифрованные данные. Обычный запуск не требует их пересборки.
Если изменены разработческие определения, запустите Godot с tools/build_private_data.gd,
затем повторите импорт/экспорт. Не включайте инструменты и исходные JSON в player package.
Исходники содержат внутренние данные и предназначены разработчику, а не игрокам.

Готовая Windows-версия запускается без Godot: распаковать Windows ZIP и открыть BLASTORIA.exe.
Сборка экспортирована; нативная проверка Windows/геймпадов выполняется отдельно.

Локальные достижения доступны в release-экспорте. При запуске F5/debug их получение отключено;
это правило спецификации, а не ошибка. Исходники предназначены разработчику и содержат внутренние данные.

В 0.6.1 предел официальных последовательностей — 51. Новые персонажи и пасхалки описаны
в docs/design; это дизайн, ещё не замена прототипных моделей/условий.
