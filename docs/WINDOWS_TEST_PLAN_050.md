# Приёмка BLASTORIA 0.5 на Windows / контроллере

1. Распаковать ZIP целиком. Запустить BLASTORIA.exe. Проверить окно, полноэкранный режим,
   звук, меню и русские надписи. Исходники отдельно открываются Godot 4.5.1 → F5.
2. Обучение: пройти урок. Аркада: органически пройти этапы 1–3. После последнего врага
   проверить немедленную победу, таймер, следующий этап, повтор карты, рекорды после перезапуска.
3. Мастерская: изменить параметры, сгенерировать несколько вариантов; поставить/стереть
   стену/врага/бонус, заполнить прямоугольник, отменить/повторить, изменить масштаб и прокрутить.
4. Проверить карту → победить/проиграть/поставить на паузу → вернуться в редактор.
   Сохранить, переименовать, создать копию, загрузить, удалить с подтверждением.
5. Экспортировать .blastmap, импортировать на другом ПК. Повторить карту и проверить совпадение.
   Пользовательская победа не должна открывать официальный этап или давать официальный артефакт.
6. Создать дуэль. Игрок 1: стрелки/Space/E; игрок 2: WASD/Enter/P. Повторить с двумя геймпадами.
7. Без физической клавиатуры: менять параметры кнопками −/+, генерировать, редактировать
   курсором и запускать карту. Проверить фокус, B для выхода из сетки, Y/X/LB/RB, скроллинг.
8. На Steam Deck/SteamOS проверить отдельно совместимость, разрешение 1280×800, контроллер,
   диалог файлов и производительность. Linux headless smoke не подтверждает эту совместимость.

При проблеме записать режим, этап/seed, точные действия, текст ошибки, ОС/GPU и приложить
снимок экрана. Не заменять результаты ручного теста предположениями по автоматическим логам.
