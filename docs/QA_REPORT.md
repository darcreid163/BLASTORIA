Сохранены предыдущие 287 проверок и добавлена 41 проверка достижений. Проверяются реальные
команды установки/взрыва, чужое самоубийство, причинная цепная реакция и независимые фитили,
изоляция пользовательских карт, пороги прогресса, повторная обработка после перезапуска,
отсутствие повторной награды, полный набор усилений, первая победа и исследование, квалификация
Арены, собственные/импортированные карты, переименование без накрутки, исключение playtest,
восстановление резервной копии, будущая версия файла, ошибка записи, уведомления и страницы UI.
Длинные пороги и серии Арены проверены контролируемыми состояниями; это не утверждение
о ручном прохождении всех достижений от начала до конца.

Отдельный тест фактической экспортированной Linux release-сборки без debug override подтверждает:
получение включено; одна установка ещё не награда; принятая установка, отход и реальный взрыв
в игровом цикле выдают достижение; сохранение и отложенная очередь читаются; пять иконок
на странице загружаются; технические API ID не показаны; пагинация работает.

В player PCK отсутствуют исходные реестры, мастер-спецификация и старые отдельные контейнеры.
Единый runtime.bin содержит только действующие открытые достижения и необходимые активные
данные, имеет заполнение до размерных блоков. Описание находки дополнительно запечатано.
Ненайденная коллекция не показывает название, ID или общее количество. Найденная показывает
публичное описание. Совместимость существующей коллекции и миграция v4 → v5 сохранены.

Экспортные проверки запущены из пустого каталога вне исходников с отдельным XDG_DATA_HOME:
запуск из каталога проекта мог бы подмешать исходные res:// файлы и не доказывал бы состав PCK.

В ходе QA исправлены два parser-уточнения типов и нормализация JSON-чисел при чтении прогресса.
После исправлений полный набор и экспортные проверки проходят.

Это локальная защита от спойлеров: ключи остаются в клиенте, весь PCK/код не зашифрован.

достижения. Нужна ручная приёмка Windows, изображения, звука и физических контроллеров.
