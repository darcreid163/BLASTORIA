# Ограничения 0.5

- Это прототип. **3 готовых официальных этапа из 100**, одна игровая тема из десяти.
- Официальные десять секретов пока только в реестре; координаты и физическая достижимость
  запланированных этапов ещё не проверены. Компас Приключения остаётся отдельным прототипом.
- Мастерская — базовый редактор. Нет новых ловушек/секретов, группового переноса/копирования,
  поворотов, полноценной панели свойств, автосохранения черновика, undo изменений названия.
- Генератор выбирает один тип врага и один тип бонуса за генерацию; разные типы можно
  расставить вручную. Нет пользовательских областей спавна/смешанных вероятностей.
- Сохранение/запуск требуют структурно корректной карты; сохранение невалидных черновиков
  пока не поддерживается. Проверка связности не доказывает тактическую проходимость.
- Максимум 32 врага / 128 бонусов / 41×31; до 200 пользовательских карт в списке и 200
  записей пользовательских версий. Пользовательские карты редактируемы получателем.
- Рекорды локальные, без серверной верификации. Дуэль не записывает соло-рекорд.
- Новый интерфейс Мастерской и официальной Аркады пока на русском; старый RU/EN сохранён.
- Графика/звук/физические контроллеры/Windows/Steam Deck не проверены в этой headless-среде.
  Синтетические события UI не являются сертификацией реального устройства.
- Нет онлайна, четырёх игроков, Steam Workshop, коммерческого релиза или консольной сборки.
- Старые Classic/Adventure сохраняют ограничения 0.4: 3 классических этапа, 1 большой мир,
  временная графика, без полной кампании/боссов/музыки.
