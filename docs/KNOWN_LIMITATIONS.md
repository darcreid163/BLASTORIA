# Ограничения 0.6.0

- 17 локальных достижений работают; Steam и серверное первенство не подключены. Остальные проектные определения не поставляются игрокам.
- В F5/debug получение отключено по требованиям спецификации; в release включено.
- Счётчики могут потерять последние незаписанные секунды при аварийном завершении. Локальные данные не являются доказательством честности.
- Накопительные Arena-награды относятся к игроку 1, без профилей второго участника. Применяются опубликованные критерии квалификации.
- Значки — временные оригинальные SVG-ресурсы, состояния различаются цветом. Финальная художественная приёмка впереди.
- Скрытые будущие данные исключены, но исполняемые условия/ключи офлайн-клиента доступны анализу. Публичные исходники содержат внутреннюю документацию.
- Кампания: первая десятка авторских карт; Аркада: три готовых этапа из ста. Контент расширяется постепенно.
- Native Windows, графика/слышимый звук, физические контроллеры и Steam Deck здесь не проверены.
