# Мастерская карт 0.5

Главное меню → Мастерская карт. Создаётся стартовый вариант. Задайте параметры слева,
нажмите «Сгенерировать новую», затем редактируйте сетку инструментами справа.
При генерации новый seed и ID; отмена возвращает предыдущую карту. «Применить правила»
меняет бомбы/таймер текущего экземпляра; размер, режим и состав генерации применяются
при следующей генерации. Сохранённая геометрия никогда не пересоздаётся при загрузке.

Поддерживаются:
- Карты нечётного размера от 11×11 до 41×31 при генерации; импорт/ручная геометрия допускает
  также чётные размеры в этих границах. Одна визуальная тема — Зелёный лабиринт.
- Пол, каменная стена, деревянный блок, старты одного/двух игроков.
- Патрульный, преследователь, бомбардир, Страж; скорость и обязательность врага.
- Восемь существующих бонусов; открытое размещение или под блоком.
- 1–5 бомб, дальность 1–6, фитиль 90–600 тиков, детонатор, лимит 0–1800 секунд.
- Соло: уничтожение обязательных врагов; дуэль: последний живой игрок. Лимит соло —
  поражение; лимит дуэли — ничья. Кампанейские подкрепления здесь не применяются.

Сетка: ЛКМ — поставить; ПКМ/средняя кнопка — выбрать тип объекта под курсором.
«Пол / стереть» удаляет врагов/бонусы в клетке, но старты переносятся инструментом старта.
Для переноса врага: стереть старое место и поставить новое. Свойства применяются при постановке.
«Прямоугольник» заполняет область между двумя выбранными клетками; границы остаются стенами.
Отмена/повтор хранит до 50 полных состояний. Кнопки масштаба и полосы прокрутки меняют обзор.
Курсор с контроллера прокручивает сетку при выходе за видимую область.

«Проверить карту» не записывает рекорды. После результата/паузы «Вернуться в редактор»
возвращает тот же экземпляр. «Играть на рекорд» записывает только успешное соло в отдельную
таблицу по ID + revision + отпечатку игровых данных. Последние 200 версий хранятся локально.
Пользовательские карты не меняют кампанию, официальный Arcade или коллекцию артефактов.

Сохранение: название/автор в верхних полях → «Сохранить». Переименование — загрузить,
изменить название, сохранить. «Создать копию» создаёт новый ID, затем нужно сохранить.
«Мои карты» показывает до 200 карт; удаление требует подтверждения.
Не сохранённые изменения текущей сессии доступны при возврате из главного меню, но теряются
при закрытии программы. Автосохранения черновика пока нет.

## Обмен

«Экспорт .blastmap» открывает выбор файла. Передайте файл другу самостоятельно.
«Импорт .blastmap» проверяет файл и добавляет новый экземпляр в «Мои карты».
ID отправителя не используется для записи: импорт создаёт новый ID и не заменяет чужую карту.
Все карты формата 1 доступны для редактирования получателем; авторские разрешения/лицензии
контента нужно согласовать отдельно. Steam Workshop и сетевой обмен пока не подключены.

Формат 1 — UTF-8 JSON, не скрипт/Resource. Максимум 256 КиБ; неизвестные поля и типы отвергаются.
Обязательные поля: format, id, revision, title, author, description, created, modified, mode,
theme, width, height, seed, generator_version, generation, rows, spawns, enemies, powerups,
rules, secrets. generation хранит выбранную конфигурацию; rows — полную итоговую геометрию.
Числа нормализуются перед хешированием: JSON float и целое представляют одинаковые правила.

Только # (стена), C (блок), . (пол); замкнутая граница; 1–2 старта; 1–32 врага для соло,
0 для дуэли; до 128 бонусов. Проверяются стартовые укрытия, достижимость с разрушением блоков,
отсутствие наложений, допустимые числовые пределы и минимальная дистанция врага от старта.
Это структурная проверка, не доказательство тактической проходимости: таймер, ИИ и цепочки
могут сделать карту трудной. Обязательна пробная игра. Гарантированного решателя нет.

Пока не поддерживаются новые ловушки/двери/вода/лёд/телепорты, секретные испытания,
произвольные команды, файлы ресурсов, команды операционной системы или код.
Неподдерживаемые настройки отклоняются с объяснением, а не заменяются другими объектами.
