# BLASTORIA 0.7.1 — Steam preflight / доставка тестовых пакетов
Дата: 2026-10-16.

## Фактическая основа
Основа этого PR — `codex/scope-and-steam-review-0.7.0` (PR #11). Это опубликованная в GitHub версия **0.7.0-dev**, а не ранее потерянный локальный черновик. Реально подтверждённый отчёт Work: 431 тест / 0 ошибок, Windows/Linux export, Linux UI в 14 языках. Здесь мы воспроизводим эти проверки на независимом runner.

Ветка `codex/steam-ci-and-packages-0.7.1` содержит работу над релизным процессом, не увеличивает объём игровых уровней и не делает игру автоматически готовой к продаже.

## Артефакты GitHub Actions
Workflow: `.github/workflows/steam-preflight-071.yml`.

1. **Godot Developer Project**: ZIP полной исходной рабочей копии из GitHub, включая конфигурацию и документы. Только для разработчиков; **не распространять покупателям** (там есть технические данные о скрытых механиках).
2. **Windows x64 QA**: ZIP для тестирования на Windows, с `BLASTORIA.exe` и обязательными объявлениями лицензий, без разработческих каталогов.
3. **Linux x64 QA**: ZIP для тестирования Linux, с исполняемым файлом и лицензиями.
4. SHA-256 и логи QA.
5. `steam_preflight_report.json` — объективный source-only результат и список ещё не закрытых релизных требований.

Если тесты провалятся, сборка игрокам **не выдаётся**. Если доступность официальных Godot export templates ограничена, исходный проект и отчёт QA могут появиться раньше PC-архивов. Готовность архивов подтверждается только успешным workflow и существованием его artifacts.

### Запуск игроком
Windows: извлечь Windows QA ZIP в пустой каталог, запустить `BLASTORIA.exe`.
Linux: извлечь Linux QA ZIP, дать `BLASTORIA.x86_64` право на выполнение, запустить.
Это разработческие кандидаты, **не опубликованная Steam 1.0**.

### Проверка самостоятельно в Godot
Установить Godot **4.5.1 Standard** и открыть `project.godot`.
F5 — запуск. В каталоге проекта: `python3 tools/verify.py --godot <godot-binary>`.
Чтобы пересчитать исходный аудит: `python3 tools/steam_preflight.py --output steam_preflight_report.json`.

## Решение о первом коммерческом релизе
**Оставить 51 уровень** первого законченного релиза, остальные 49 — будущие дополнения. Не изображать конфигурации/будущие слоты как готовые этапы.

Steam Workshop, собственный онлайн и мировой реестр не обязательны для локальной коммерческой игры; их нельзя включать в обещания магазина до реальной реализации. Steam Achievements, Steam Cloud, Remote Play Together и Verified Deck тоже отмечать только после практических тестов.

Предварительная цена $7.99 (США) из `docs/steam/STEAM_MARKET_REVIEW_2026_10_16.md` остаётся **гипотезой** для законченной игры, не ценой, назначенной в Steam.
