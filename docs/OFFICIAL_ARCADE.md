# Официальная Аркада — две главы 0.7.4

Доступны двадцать авторских этапов: «Зелёный лабиринт» (1–10) и «Затопленные
руины» (11–20), каждый 25×17. Файлы JSON
содержат фиксированные стены, ящики, старты, врагов и предметы. Генератор Мастерской
при запуске официального этапа не вызывается. Карты 1–10 сохранены побайтно: прежние
ключи рекордов и условия действующей находки остаются совместимыми.

| Этап | Планировка и тактическая задача | Противники |
| --- | --- | --- |
| 1. Двор садовника | Первое укрытие, центральный двор и боковые петли | Патрульный |
| 2. Две тропы | Чередующиеся перегородки, выбор обхода и разрушаемых перемычек | Патрульный, преследователь |
| 3. Цепной сад | Каменные острова, карманы и места для нескольких бомб | Два патрульных, преследователь |
| 4. Перекрёсток | Четыре острова, центральные пересечения, бомба с несколькими путями отхода | Два патрульных, преследователь |
| 5. Обходные пути | Сдвинутые вертикальные перегородки: открыть перемычку или пройти длинным путём | Патрульный, два преследователя |
| 6. Галерея фитилей | Три поперечные галереи; учитывать бомбы врагов, выбирать проход и подрыв | Два бомбардира, патрульный, преследователь |

## Вторая глава: «Затопленные руины»

| Этап | Планировка и тактическая задача |
| --- | --- |
| 11. Первый мост | Две переправы через канал; перейти на дальний берег и использовать каменные укрытия |
| 12. Разделённый двор | Поперечная вода, три узких перехода, выбор пути между верхним и нижним двором |
| 13. Три переправы | Два разнесённых канала, переходы на разных высотах, обход центральной каменной опоры |
| 14. Каменные острова | Четыре водных бассейна, сухие коридоры между ними, Страж и два бомбардира |
| 15. Петля течения | Водное кольцо с четырьмя проходами вокруг каменного центра; удерживать путь отхода |
| 16. Смотровые галереи | Два поперечных канала с разнесёнными мостами; учитывать огонь вдоль сухих галерей |
| 17. Ворота Стража | Два канала и каменные перегородки; два Стража повышают давление на узких переправах |
| 18. Дальний причал | Вертикальный и горизонтальный каналы, дальние обходы, семь противников разных ролей |
| 19. Перекрёстные каналы | Сетка водных преград с редкими переходами; планировать смену сектора заранее |
| 20. Сердце руин | Бассейны и разрезанный проходами центральный водоём; восемь противников, итог главы |

Вода (`~`) непроходима для всех акторов, не разрушается и останавливает луч взрыва
**до водной клетки**. Проход сквозь ящики/бомбы/огонь не позволяет плавать. Мосты —
обычная земля: по ним идут акторы и проходит огонь. Водные отметки и настилы —
трёхмерное представление того же поля, без отдельных декоративных коллизий.
Изменённые маршруты врагов следуют из фиксированных препятствий; новые типы ИИ,
движущиеся течения, электричество и затопление в реальном времени ещё не добавлены.
Мастерская поддерживает кисть воды, пипетку, undo/redo и roundtrip .blastmap; без
инструментов или сведений об официальных пасхалках.

Сложность и последовательность спроектированы, но баланс по человеческим сессиям ещё
не принят. Нельзя оценивать среднее время игрока по времени автоматического драйвера.

## Правила и рекорды

Один игрок, уничтожение обязательных врагов сразу завершает этап. Выход не требуется.
При одновременной смерти игрока и последнего врага — поражение. Пауза и итоговый экран
не увеличивают активное время. Победа открывает следующий готовый этап; Мастерская
не изменяет официальные результаты. Этапы 21+ пока не доступны. План релиза — 51.

Очки: ящик от своего огня 10; враг от своего огня 100; подобранное усиление 25;
победа 500; бонус времени 5×max(0,180−ceil(active_ticks/60)). Награды однократны.
Рекорд каждого этапа отделён по id/fingerprint; при равном счёте лучше меньшее время.
Лучшее время прохождения учитывается отдельно. Плохой результат и поражение не
заменяют рекорд победы. Данные — user://official_arcade_23.json.

Выбор этапов — страницы по десять плиток: доступные можно запустить, остальные отключены до
предыдущей победы. Страница и фокус ставятся на последний доступный этап; главы можно просматривать
в обе стороны. Рекорды тоже разделены на страницы, возврат сохраняет выбранную главу. Названия переведены
на 14 языков; обе главы и их названия проверены в интерфейсе 1280×800.

## Проверка достижимости

Для 4–20 сохранены успешные последовательности обычных команд с работающим ИИ:
tests/fixtures/arcade/*.json. Во время записи и воспроизведения не менялись позиции,
здоровье, способности, геометрия или исход вручную. Драйвер наблюдает текущее поле,
выдаёт только move/bomb/detonate; он исключён из player package вместе с записями.
Тесты воспроизводят команды, сравнивают точные очки/тики, учитывают события подбора,
проверяют заморозку результата, запись каждого рекорда и продолжение после перезапуска.
Это подтверждение существования успешного пути в текущей версии симуляции; не ручная
приёмка баланса, Windows или физических контроллеров.

Исторический resources/arcade/secrets.json — прежний разработческий план, не активный
список находок и не источник размещения новых пасхалок. Действующие определения
минимизированы в sealed runtime; полный план — docs/design/EASTER_EGGS_51_RU.md.
Эти разработческие источники не поставляются игрокам.
