# BLASTORIA 0.5.5

Распакуйте архив целиком и запустите BLASTORIA.exe. Редактор Godot не требуется.

Главное меню: Обучение, Кампания, Приключение, Аркада, Мастерская, Арена,
Коллекция секретов, Настройки, Выйти. Классическое прохождение находится в Кампании.

- Кампания: уничтожьте обязательных врагов, откройте спрятанный выход и войдите в него.
  Первые десять этапов имеют авторские карты; дальнейшая часть ещё развивается.
- Аркада: уничтожьте обязательных врагов. Выход не требуется. Доступны первые три этапа.
- Мастерская: создавайте/редактируйте карты, проверяйте, сохраняйте и обменивайтесь .blastmap.
- Личная коллекция пополняется после находок. Глобальный сервис и Steam пока не подключены.

Управление первого игрока: стрелки, Space — бомба, E — детонатор при наличии способности.
Второй игрок: WASD, Enter, P. Геймпад: крестовина, A — бомба, B — детонатор.
Esc / Start — пауза. F11 — полный экран. Переназначение находится в Настройках.

Это версия в разработке. Windows EXE экспортирован; запуск на Windows и физических
контроллерах в среде сборки не проверялся. Для сообщения об ошибке запишите режим,
этап/seed, точные действия и текст ошибки.
