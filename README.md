# BLASTORIA: Worlds of Chaos

**0.4.0-dev — игровой прототип для Windows, Godot 4.5.1 Standard / GDScript.**
Оригинальная аркада с лабиринтами, бомбами, короткой кампанией и локальной ареной.
Графика пока процедурная: реальные 3D-объекты и камера с фиксированным наклонным углом.

## Запуск

Windows: распакуйте весь архив сборки и запустите `BLASTORIA.exe`. Редактор не нужен.
EXE версии 0.4.0 экспортирован, но **новая версия ещё не проверена на Windows**.
Скриншоты владельца подтвердили запуск меню и игрового поля предыдущей 0.2.

Исходники: установите [Godot 4.5.1 Standard](https://godotengine.org/download/archive/4.5.1-stable/),
импортируйте `project.godot`, дождитесь импорта и нажмите F5.
Подробно о ZIP с исходниками: [инструкция запуска](docs/SOURCE_GUIDE_RU.md).
Эта версия закреплена для воспроизводимости, не объявляется новейшей.
Ссылка на 4.7.2 из README исходного 0.1 не использовалась для проверки.

## Что работает в коде 0.4.0

- **Приключение:** большой лабиринт 41×31, следующая камера, исследование и две формы карты.
- **Классика:** три этапа 21×15, скрытый выход, контактные враги, таймер 200 секунд и Стражи.
- Восемь усилений, включая дистанционный подрыв, проходы и защиту.
- Первая пасхалка «Призрачный компас», коллекция и оригинальная модель. Остальные 9 пока в дизайне.
- **Обучение:** авторская карта без врагов, пошаговые задания: движение, бомба, усиление, выход.
- Звуковые эффекты движения, бомб, фитиля, взрывов, предметов, исхода и меню.
- Настройки общей громкости, эффектов и меню; переназначение клавиш обоих игроков.
- **Аркада:** отдельный одиночный забег из трёх уровней, очки, таймер и локальные рекорды.
- Старая техническая кампания доступна через меню «Приключение»; её прогресс сохранён.
- Арена на двоих с поворотной симметрией; новый вход создаёт новую карту, повтор сохраняет seed.
- Бомбы: 2,5 секунды, радиус 1 в Классике / 2 в остальных режимах, лимит 1, огонь 0,5 секунды.
- Препятствия, цепные реакции, поражение, победа, одновременная ничья.
- В старых режимах сохранены три базовых усиления и их лимиты.
- Меню, пауза, повтор, выход, RU/EN, переключение полного экрана.
- Сохранение прогресса, рекордов, языка, громкости, клавиш и полного экрана с резервной копией.
- ИИ с картой опасности и поиском пути отхода; временная консервативная модель.

## Управление

| Действие | Игрок 1 | Игрок 2 |
| --- | --- | --- |
| Движение | WASD | Стрелки |
| Бомба | Пробел | Enter |
| Геймпад | Устройство 0: крестовина + A | Устройство 1: крестовина + A |

E / B геймпада — дистанционный подрыв при наличии RC (второй игрок: P).
Tab / Select — скрыть/мини/большая карта Приключения; карта не останавливает игру.
Esc / Start — пауза; R — повтор из паузы или результатов; F11 — полный экран.
Меню доступно мышью и стандартными UI-действиями Godot. Физические геймпады ещё не проверены.
В кампании уничтожьте всех врагов и дойдите до выхода: после победы над врагами он станет зелёным.
Сохранение: `user://profile.json` и резервная копия `profile.json.bak`.
Точный пользовательский каталог можно открыть через редактор (Open User Data Folder).
Главное «Продолжить» сейчас начинает единственный большой уровень заново. Продолжение старой
кампании находится внутри меню «Приключение». Сохранения середины боя пока нет.

## Аркада

В меню выберите «Аркада», прочитайте правила и нажмите «Начать забег».
Одна жизнь на три уровня: ящик +10, враг +100, предмет +25, прохождение +500.
За оставшиеся до 180 секунд уровня полные секунды начисляется по 5 очков.
Очки за разрушение начисляются только от бомб игрока. Таймер исключает паузу и меню.
Лучший счёт сохраняется при победе/поражении; лучшее время — только за весь пройденный забег.
Повтор обнуляет забег. Выход в меню прерывает его без записи рекорда.
Подробные правила: [дополнение к промпту](docs/ARCADE_ADDENDUM_RU.md).

## Проверка и экспорт

```sh
python tools/verify.py --godot /path/to/godot
mkdir -p builds/windows
godot --headless --path . --export-release "Windows Desktop"
```

Для экспорта установите официальные шаблоны **той же версии 4.5.1**.
Проверки исполняют GDScript в настоящем Godot. Доказательства: `docs/qa/*.txt`.
Linux QA preset служит для проверки экспортированной упаковки; Linux не заявлен целевой релизной платформой.
