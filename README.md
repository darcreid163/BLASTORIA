# BLASTORIA: Worlds of Chaos

**0.2.0-dev — игровой прототип для Windows, Godot 4.5.1 Standard / GDScript.**
Оригинальная аркада с лабиринтами, бомбами, короткой кампанией и локальной ареной.
Графика пока процедурная: реальные 3D-объекты и фиксированная наклонная камера.

## Запуск

Windows: распакуйте весь архив сборки и запустите `BLASTORIA.exe`. Редактор не нужен.
EXE экспортирован, но **запуск на Windows и визуальная приёмка ещё не проверены**.

Исходники: установите [Godot 4.5.1 Standard](https://godotengine.org/download/archive/4.5.1-stable/),
импортируйте `project.godot`, дождитесь импорта и нажмите F5.
Эта версия закреплена для воспроизводимости, не объявляется новейшей.
Ссылка на 4.7.2 из README исходного 0.1 не использовалась для проверки.

## Что работает в коде 0.2

- Три последовательных уровня с фиксированными seed и 1/2/3 врагами; это техническая мини-кампания.
- Арена на двоих с поворотной симметрией; новый вход создаёт новую карту, повтор сохраняет seed.
- Бомбы: 2,5 секунды, радиус 2, лимит 1, огонь 0,5 секунды.
- Препятствия, цепные реакции, поражение, победа, одновременная ничья.
- Усиления: +B количество бомб, +R радиус, +S скорость, с верхними ограничениями.
- Меню, пауза, повтор, выход, RU/EN, переключение полного экрана.
- Сохранение открытого уровня и языка с резервной копией.
- ИИ с картой опасности и поиском пути отхода; временная консервативная модель.

## Управление

| Действие | Игрок 1 | Игрок 2 |
| --- | --- | --- |
| Движение | WASD | Стрелки |
| Бомба | Пробел | Enter |
| Геймпад | Устройство 0: крестовина + A | Устройство 1: крестовина + A |

Esc / Start — пауза; R — повтор из паузы или результатов; F11 — полный экран.
Меню доступно мышью и стандартными UI-действиями Godot. Физические геймпады ещё не проверены.
В кампании уничтожьте всех врагов и дойдите до выхода: после победы над врагами он станет зелёным.
Сохранение: `user://profile.json` и резервная копия `profile.json.bak`.
Точный пользовательский каталог можно открыть через редактор (Open User Data Folder).
Продолжение загружает открытый уровень, а не середину боя. Запуск с первого уровня не стирает прогресс.

## Проверка и экспорт

```sh
python tools/verify.py --godot /path/to/godot
mkdir -p builds/windows
godot --headless --path . --export-release "Windows Desktop"
```

Для экспорта установите официальные шаблоны **той же версии 4.5.1**.
Проверки исполняют GDScript в настоящем Godot. Доказательства: `docs/qa/*.txt`.
Linux QA preset служит для проверки экспортированной упаковки; Linux не заявлен целевой релизной платформой.
