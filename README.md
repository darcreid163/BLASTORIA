# BLASTORIA: Worlds of Chaos

**0.7.4-dev — вторая глава Аркады «Затопленные руины», вода и выбор глав.**
Godot 4.5.1 Standard / GDScript / GL Compatibility.

## Запуск

Для игры на Windows распакуйте `BLASTORIA_0_7_2_Windows_x64.zip` в отдельную папку
и откройте **BLASTORIA.exe**. Установка Godot для этого не требуется.

`BLASTORIA_0_7_2_Godot_Source.zip` — проект для разработки. Распакуйте его,
импортируйте `project.godot` в Godot 4.5.1 Standard, дождитесь импорта и нажмите F5.
Он содержит техническую документацию и разработческие каталоги; не поставляйте его
игрокам вместе с исполняемым файлом. Windows EXE экспортирован автоматически;
ручная проверка на Windows ещё нужна.

## Что доступно

| Раздел | Текущее поведение |
| --- | --- |
| Аркада | Один игрок; двадцать авторских этапов в двух главах, победа после последнего обязательного врага; отдельные рекорды очков и времени каждого этапа |
| Арена | Два локальных игрока на одном ПК; последний выживший побеждает, одновременная гибель даёт ничью |
| Приключение | Продолжение / новое путешествие с жизнями и скрытым выходом; прежний прогресс сохранён. Десять авторских этапов путешествия, далее временная геометрия; отдельная большая область Руин |
| Мастерская | Соло, совместное прохождение, дуэль либо соло против ботов; размер, состав врагов, скорость, бонусы и правила бомб; редактор с кистью воды, undo/redo, библиотека, импорт/экспорт .blastmap |
| Обучение | Справочник восьми бонусов и четырёх действующих ролей, авторский урок; справочник доступен также из паузы |
| Коллекция | Только личные обнаруженные предметы; мировой сервис пока не подключён |
| Достижения | 17 локальных действующих наград; в F5/debug получение отключено; Steam пока не подключён |

План первого коммерческого релиза — **51 готовый уровень**, затем ещё 49 в обновлениях.
Программный предел 51 не означает, что все авторские карты уже произведены.

Меню → Язык: поиск по родному, английскому или переведённому названию; выбор сохраняется.
Тексты: русский, английский, японский, корейский, упрощённый китайский, хинди,
индонезийский, тайский, вьетнамский, французский, итальянский, немецкий, арабский, турецкий.
Арабские панели используют RTL; поле и направления управления не зеркалируются.
Названия и авторы пользовательских карт остаются как написаны.
Автоматическая полнота и отображение проверены; вычитка носителями остаётся задачей релиза.

Игрок 1: стрелки + Space; игрок 2: WASD + Enter. Esc — пауза; R — повтор после
поражения/на паузе; F11 — полный экран. Клавиши меняются в настройках. Геймпад:
крестовина, A — бомба, B — дистанционный подрыв при наличии усиления, Start — пауза.
X первого геймпада на экране результата — быстрый повтор. Физические контроллеры и Steam Deck ещё требуют ручной приёмки.

HUD показывает запас бомб, дальность, активные способности и текущую клавишу
дистанционного подрыва. При подборе появляется краткое объяснение. Итог этапа
разбивает очки на ящики, врагов, бонусы, завершение и время; при поражении
показывает известную причину: огонь, касание монстра или истечение лимита карты.

Обычная бомба показывает оставшийся фитиль четырьмя делениями; в конце отсчёт
ускоряет пульсацию. Дистанционная узнаётся по бирюзовой антенне и постоянным
меткам: её нельзя принять за бомбу с истекающим таймером. Эффекты огня совпадают
с опасными клетками. Разрушение, подбор и гибель получили короткие локальные
эффекты; на паузе они замирают. Звуки синтезированы заново, важные сигналы
защищены от вытеснения шагами. Музыка и полноценная аудиоприёмка ещё впереди.

Вторая глава Аркады — этапы 11–20 «Затопленные руины». Вода непроходима
для героя и врагов, останавливает взрыв и не разрушается. Мосты — проходимая
земля: огонь проходит по ним как обычно. Способности прохода не дают плавания.
Выбор этапов и рекорды разделены по главам; прежние карты и ключи рекордов
сохранены. Электричество, течение и затопление в реальном времени ещё не добавлены.
